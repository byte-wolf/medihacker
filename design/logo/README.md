# DOKuTOR logo

DOKuTOR plays on *Doktor* (German) and *doctor* (English), and on *documents*. The lower-case **u** is a stethoscope.

## Final logo (`final/`)

| File | Use |
|---|---|
| `dokutor-wordmark.svg` | Wordmark on light backgrounds |
| `dokutor-wordmark-on-dark.svg` | Wordmark on dark backgrounds (lighter blue) |
| `dokutor-wordmark-mono.svg` | Single colour; takes the surrounding text colour (`currentColor`) |
| `dokutor-icon.svg` | App icon / favicon: white stethoscope u on a blue rounded square |
| `dokutor-icon-on-white.svg` | The same icon in blue on white |
| `preview.html` | All versions at real sizes, including a 22 px header and 16–128 px icons |

All letters are drawn as paths on one grid, so the logo needs no font. Colours: Carbon blue `#0f62fe` (dark version `#78a9ff`) and ink `#161616`. In an app header, give the wordmark about 32–40 px height; the image reserves space below the baseline for the stethoscope tube.

To change the shapes or colours, edit `final.py` and run:

```bash
python3 design/logo/final.py
```

## Concepts

`index.html` shows the six first concepts (`1-…svg` to `6-…svg`), generated by `build.py`. Concept 1 was chosen and refined into `final/`.

The logo is not used in the app yet.
